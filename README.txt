AERA — готовая структура лендинга
================================

Файлы:
- index.html
- styles.css
- script.js
- assets/ — сюда положить изображения

ВАЖНО: создай папку assets и добавь свои изображения с такими именами:

hero.jpg
texture-main.jpg
texture-top.jpg
texture-bottom.jpg

serum.jpg
cream.jpg
cleanser.jpg

ingredient-01.jpg
ingredient-02.jpg
ingredient-03.jpg
ingredient-04.jpg

campaign.jpg

Как запустить:
1. Открой папку aera-site в VS Code.
2. Установи Live Server (если ещё нет).
3. Правой кнопкой по index.html -> Open with Live Server.
4. Если фото не появляются — проверь точные имена файлов в assets.

Что уже есть:
- адаптив под телефон;
- анимированный loader;
- reveal анимации при скролле;
- прозрачное меню, которое меняется при прокрутке;
- параллакс hero;
- анимация флакона AERA на scroll;
- hover-анимации карточек;
- плавающий preview ингредиентов;
- большая texture-секция;
- manifesto;
- campaign section;
- newsletter;
- полноценный footer.
